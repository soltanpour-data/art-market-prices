# Data

## Files

| File | Contents |
|---|---|
| `raw_auction_data.csv` | Lot-level results exactly as collected: 4,000 lots, 2005–2015 |
| `clean_auction_data.csv` | After step 01: sold lots only, constant-2005 GBP, log prices |
| `model_data.csv` | After step 03: modelling-ready design matrix with dummies |
| `price_index.csv` | After step 05: quarterly hedonic index (2005Q1 = 100) |

## Schema of `raw_auction_data.csv`

| Column | Type | Description |
|---|---|---|
| `lot_id` | string | Unique lot identifier |
| `artist` | string | Artist name |
| `artist_tier` | string | `blue_chip` / `mid_career` / `emerging` (descriptive) |
| `segment` | string | Market segment: Old Masters, Impressionist & Modern, Post-War & Contemporary |
| `auction_house` | string | Christie's, Sotheby's, or Bonhams |
| `sale_date` | date | Sale date (YYYY-MM-DD) |
| `sale_year`, `sale_quarter` | int | Year and quarter of sale |
| `medium` | string | Oil on canvas, Oil on panel, Watercolor, Works on paper, Sculpture |
| `width_cm`, `height_cm` | float | Dimensions in centimetres |
| `signed` | bool | Whether the work is signed |
| `provenance_count` | int | Number of recorded provenance entries |
| `exhibition_count` | int | Number of recorded exhibitions |
| `sold` | bool | Whether the lot sold (unsold = bought in, no price) |
| `hammer_price_gbp` | float | Hammer price in GBP (empty when unsold) |

## Using real data

The bundled data is **synthetic** (generated by
`src/00_generate_sample_data.py` with a fixed seed, so it is fully
reproducible). To analyse real auction results:

1. Assemble lot-level results with the columns above and save as
   `data/raw_auction_data.csv` (column order does not matter; extra columns
   are ignored).
2. Delete or ignore `clean_auction_data.csv`, `model_data.csv` and
   `price_index.csv` — they are regenerated.
3. Run `python src/run_all.py` starting from step 01
   (`python src/01_data_cleaning.py`, then 02, 03, …).

Notes for real data: convert all prices to GBP before loading (or adapt
step 01), and expect the ADF / ARIMA steps to behave differently — real
art indices are usually non-stationary, which the pipeline handles by
differencing.
